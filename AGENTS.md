# Agent Instructions

This repository contains a static Bootstrap 5.3.3 HTML page. See [README.md](README.md) for the project note and [Bootstrap-git.html](Bootstrap-git.html) for the implementation.

## Formatting

- Use Prettier for HTML formatting.
- Preserve the existing four-space indentation and CRLF line endings.
- Keep Bootstrap CDN URLs and Bootstrap class names unchanged unless the task explicitly requires them to change.
- Format only files edited for the task.
- There is no local Prettier configuration, package script, build step, or test suite. Use the VS Code Prettier extension or an available global `prettier` executable; do not add package tooling unless requested.

## Validation

- Open `Bootstrap-git.html` in a browser after markup changes and check the responsive layout.
